# Git 版本控制练习

## 项目简介

这是我学习 Git 版本控制的实操练习项目，涵盖从本地仓库初始化到 GitHub Pages 部署的完整流程。

## 技术栈

- Git
- GitHub
- GitHub Pages

## 实现内容

1. **本地仓库初始化**：`git init` 创建仓库，理解 `.git` 目录结构
2. **基本操作**：`add`、`commit`、`status`、`log` 等命令的使用
3. **远程仓库关联**：`git remote add` 关联 GitHub 仓库
4. **推送与拉取**：`push`、`pull` 的使用与冲突处理
5. **分支管理**：`branch`、`checkout`、`merge` 基础操作
6. **GitHub Pages 部署**：将静态 HTML 页面部署到公网

## 收获

- 理解了工作区、暂存区、本地仓库、远程仓库的关系
- 掌握了 Conventional Commits 提交信息规范
- 学会了用 `.gitignore` 排除敏感文件
- 解决了 GitHub Pages 子路径部署的资源引用问题
